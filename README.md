# BOT-multifuncional-para-Discord
Bot de Discord em Python (discord.py + aiohttp) com cinco comandos: !perfil mostra dados do usuário, !meme envia memes brasileiros, !tabela exibe a classificação do Brasileirão Série A (pontos, jogos e saldo de gols) via football-data.org, !fala cumprimenta e !help lista todos os comandos disponíveis.
